M3 Expressive Carousel

布局完全由 m3e-plus 仓库里的 carousel-keylines.ts 计算（Compose Keylines / Strategy 移植）。拖拽、触控板、滚轮、键盘、点击都能用；松手按速度惯性滑行再弹簧吸附，拉过头有 Android 12 式拉伸回弹。

— fps

Multi-browse 多浏览

一大 + 中 + 小，Arrangement 自动挑成本最低的组合。滑动时焦点从左边沿着 keyline 步进移到右边，快速甩动可以一次跨多张。

Hero 主角

一张大图 + 一张小预览，每次最多翻一张（像 Pager），首选尺寸为 0 时铺满容器。

Centered Hero 居中主角

大图居中、两侧各一张小图，至少 3 张才居中，否则退回左对齐。

Uncontained 无边界

固定宽度平铺，末尾露出被裁切的一张，自由滚动不吸附（尺寸跟“首选尺寸”走）。

Full-screen 竖向全屏

同一套引擎换到纵轴：每屏一张，上下翻页，翻页时下一张从 10px 的锚点“长”出来。

键盘：聚焦任意轮播后 ←→（竖向是 ↑↓）翻页，Home/End 到两端。

开启 Keyline 调试 能看到每条 keyline：紫色是焦点，粉色是锚点，虚线是 pivot；下方实时显示当前处于 start 步进、默认还是 end 步进。

开启 慢放 看吸附弹簧和遮罩变形的细节。

keyline 数学：AndroidX Compose Material3 carousel（Apache-2.0），由 m3e-plus 移植并对 Kotlin oracle 校验。
手势物理：VelocityTracker(Lsq2)、Android spline 衰减、Pager 吸附规则，移植自 AndroidX，速度追踪与衰减代码取自 md3e-web-unofficial（Apache-2.0）。
遮罩、拉伸与调试图层为本演示独立实现，未改动仓库。
