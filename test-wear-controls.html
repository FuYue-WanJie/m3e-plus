Wear 专区新组件：LevelIndicator / ScrollIndicator / Stepper

对齐 AndroidX Wear material3：LevelIndicator（72° 弧、右侧、底部向上填充）、ScrollIndicator（position/size 双 fraction + 500ms tween + 0.3–0.7 clamp）、Stepper（上+/下−、repeatable、pill→small morph）。

LevelIndicator（value 0 / 0.35 / 0.7 / 1 / disabled / left）

ScrollIndicator（position 0 / 0.5 / 1；size 0.3 / 0.5 / 0.7；动画演示）

Stepper（配 LevelIndicator + 内容）

ScreenScaffold 模式：滚动列表 + ScrollIndicator(for) + EdgeButton(for)

滚到底部时 EdgeButton 从 0 长到满高并淡入，往上滚又收起；右侧滚动条自动跟随。两块：静态截图同时展示顶部与底部状态，第三块可以自己滚。

TransformingList（TransformingLazyColumn）：靠近上下边缘的条目缩小 + 淡出

同样接了 ScrollIndicator 和 EdgeButton。前三块是固定滚动位置的静态对比，最后一块可以自己滚。
