# 📍 M3E Roadmap

This roadmap presents the ongoing development, future direction, and past accomplishments of M3E.

## 🟡 Current

- 2.10.x Release

## 🔮 Future

### ✨ Components

The following components are planned for future release (in no particular order):

- Inputs (numeric, masked)
- Form‑field derived composite inputs (text, date, number, combobox, etc.)
- Scroll view (overscroll stretch effect, auto-hide scrollbars)
- Carousel

### 📜 Building with AI

- MCP Server enabling IDEs and AI tools to query local knowledge about components and documentation

## 🏛️ Past Milestones

- **2.10.0 – 2.10.2 — Feature release + patch releases**
  Added `@wanjie/m3e-web/callout`, switch improvements, loading-indicator pull-to-refresh support, bug fixes.

- **2.9.0 – 2.9.2 — Feature release + patch releases**
  Updated `@wanjie/m3e-web/theme` to use 2025 spec (correcting color variant support), updated components to support standard/expressive motion, bug fixes.

- **2.8.0 – 2.8.3 — Feature release + patch releases**
  Added `@wanjie/m3e-web/gestures`, form-field manual error state, select settable value, bug fixes.

- **2.7.0 – 2.7.12 — Feature release + patch releases**
  Added `@wanjie/m3e-web/date-input`, text scaling support, bug fixes.

- **2.6.0 – 2.6.3 — Feature release + patch releases**
  Added `@wanjie/m3e-web/timepicker`, bug fixes.

- **2.5.0 – 2.5.16 — Feature release + patch releases**
  Added `@wanjie/m3e-web/breadcrumb`, `@wanjie/m3e-web/content-pane`, bug fixes.

- **2.4.0 – 2.4.1 — Feature release + patch releases**
  Added `@wanjie/m3e-web/tree`, bug fixes.

- **2.3.0 – 2.3.2 — Feature release + patch releases**
  Added `@wanjie/m3e-web/split-pane`, `@wanjie/m3e-web/skeleton`, and `@wanjie/m3e-icons`, bug fixes.

- **2.2.0 – 2.2.2 — Feature release + patch releases**
  Added `@wanjie/m3e-web/calendar`, `@wanjie/m3e-web/datepicker`, `@wanjie/m3e-web/search`, and `change` event to `@wanjie/m3e-web/autocomplete`, bug fixes.

- **2.1.0 – 2.1.3 — Feature + patch releases**
  Enhancements to `m3e-autocomplete` and `m3e-input-chip-set`, bug fixes.

- **2.0.1 – 2.0.5 — Patch releases**  
  Bug fixes, SSR support for React.

- **2.0.0 — Major release**  
  Unified architecture under `@wanjie/m3e-web`, introduced `@wanjie/m3e-react` (React bindings), consolidated components, and deprecated legacy per‑component packages.

- **1.3.0 – 1.3.1 — Feature + patch releases**  
  Added `@wanjie/m3e-bottom-sheet` and delivered follow‑up bug fixes.

- **1.2.1 – 1.2.2 — Patch releases**  
  Bug fixes.

- **1.2.0 — Feature release**  
  Bug fixes, expressive updates to `@wanjie/m3e-menu`, and introduction of the rich tooltip in `@wanjie/m3e-tooltip`.

- **1.1.8 – 1.1.11 — Patch releases**  
  Bug fixes.

- **1.1.7 — Feature release**  
  Added `@wanjie/m3e-avatar`, expressive updates to `@wanjie/m3e-list`, and new selection/action patterns.

- **1.1.4 – 1.1.6 — Patch releases**  
  Bug fixes.

- **1.1.3 — Feature release**  
  Bug fixes and added the wavy appearance variant to `@wanjie/m3e-progress-indicator`.

- **1.1.1 – 1.1.2 — Patch releases**  
  Bug fixes.

- **1.1.0 — Feature release**  
  Added `@wanjie/m3e-paginator`, bundle size reductions, and RTL layout fixes.

- **1.0.6 — Feature release**  
  Added `@wanjie/m3e-autocomplete`, `@wanjie/m3e-select`, and `@wanjie/m3e-option`.

- **1.0.5 — Patch release**  
  Bug fixes and converted `@wanjie/m3e-all` into a pure meta‑package.

- **1.0.4 — Patch release**  
  Bug fixes.

- **1.0.3 — Feature release**  
  Added `@wanjie/m3e-stepper`.

- **1.0.1 – 1.0.2 — Patch releases**  
  Bug fixes.

- **1.0.0 — Stable release**  
  First full, stable version of the M3E component library.

- **1.0.0 RC1 – RC4 — Release candidates**  
  Initial component development, testing, and documentation.
